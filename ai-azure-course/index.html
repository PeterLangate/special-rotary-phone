LANGATE · AI AZURE COURSE

Manage Azure with
Claude Code

Langates YouTube-serie om hur konsulter och administratörer sköter Microsoft Azure via terminalen med Claude Code — från första setup och tenant-anslutning till dagliga utforsknings- och driftflöden. Serieplanen ramar in bågen; varje avsnitt levereras som ett fullständigt inspelningsmanus (A4, PDF-klart) med demo-steg, on-screen callouts och talarstöd.
