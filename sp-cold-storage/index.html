LANGATE · SP COLD STORAGE

SharePoint
Cold Storage

A SharePoint solution that moves heavy media files off SharePoint's default storage and into Azure Blob Storage's Cold tier for a much lower running cost — while keeping the same download experience inside SharePoint via a server-side proxy that never lets the storage keys leave the tenant. Archiving is driven by Azure Blob Lifecycle Management rules. Technical documentation plus two clickable mockups covering the end-user download path and the admin configuration flow. The underlying documents ship in Swedish.
