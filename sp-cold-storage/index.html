LANGATE · SP COLD STORAGE

SharePoint
Cold Storage

SharePoint-lösning som flyttar tunga mediafiler till Azure Blob Storage Cold-nivån för lägre lagringskostnad — men behåller nedladdning direkt från SharePoint-UX:et via en proxy där lagringsnycklarna aldrig lämnar servermiljön. Automatisk arkivering styrs via Azure Blob Lifecycle Management. Teknisk dokumentation plus två klickbara mockups som visar nedladdnings- och konfigurationsflödet.

Arkitektur, kostnad och driftmodell — kapitel-för-kapitel

Fullständig teknisk genomgång av SP Cold Storage — dataflödet från SharePoint till Azure Blob Cold, proxy-arkitekturen som håller lagringsnycklar på servern, Lifecycle Management-regler för automatisk arkivering, kostnadskalkyl mot Hot-nivån och driftmodell för uppföljning. Klar för PDF-utskrift.
